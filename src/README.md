# CAD 转 SolidWorks 钣金

把 DXF / DWG 展开图做成可编辑的 SolidWorks 钣金零件。轮廓、孔和折弯线由程序重画，不把 CAD 原图直接导进草图。

需要 Windows、已安装的 SolidWorks，以及带 pywin32 的 Python。本仓库的自动化测试不连接 SolidWorks。

## 放到本机

把这个文件夹整份拷到 Windows 电脑，例如 `D:\工程\钣金导入\程序`。不要覆盖旁边的「导出」目录。

1. 双击 `安装到本机.bat`（只需一次）。装完后桌面会有「CAD转SolidWorks」。
2. 先打开 SolidWorks，再双击桌面上的「CAD转SolidWorks」。

顶栏有「① 钣金展开」「② 滚筒零件」「③ 车件」。

## 运行

```bash
pip install -r requirements.txt
python app.py
```

打开图纸后：

1. 在左侧核对板厚、折弯半径、角度。这些是单件生成的参数，也是一键导出弹窗的初始值。
2. 点「生成钣金零件」只做当前选中的那一块。
3. 点「一键全部导出」会先弹出确认窗，不会立刻开始。窗口里能改输出目录、默认板厚、半径和角度。点「开始导出」才逐件生成；点「取消」关闭窗口。

默认输出目录是 `D:\工程\钣金导入\导出\{图名}\`。弹窗里的路径可以改。

## 文件名和厚度

零件按图上的位置从上到下、从左到右编号。件数优先读附近的「J1 X 2件」这类标注，没有就按 1 件。厚度读该行最上面的大字（例如 `2mm`）；这一行没有大字时，用弹窗里的默认板厚，并在日志里写明。

```text
01×2 2mm.SLDPRT
02×1 1.5mm.SLDPRT
```

同名文件已存在时，在主名后加 `_2`、`_3`，主名仍是上面的格式。

## 折弯

- 折弯位置是折弯中心线。
- 红实线、「中心线」层上的开放线，以及原来的红虚线 / 折弯层规则，合并后去重。孔中心的短十字线不算折弯线。
- 识别到的折弯线保持原长，不延长到零件边界。
- 释放槽的扩法和补槽见 [BEND_RELIEF.md](BEND_RELIEF.md)。折弯超时或多次扩大仍失败时，保存平板，并留下名为「折弯线_手折参考」的草图。

## 车件

顶栏「③ 车件」可以一件出图，也可以导入文件夹。一张图一个文件时，选文件夹后每张 DXF 或 DWG 各旋转成一个零件，文件名用图名。螺纹和钻孔深度只取该图上的标注。这里没有 SolidWorks，不能替你确认旋转结果。

## 测试

```bash
python -m unittest discover -s tests
```

这些测试检查识别、厚度、命名和释放槽几何，不会启动 SolidWorks。

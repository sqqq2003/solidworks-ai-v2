- `_create_bends_with_fallbacks()` 改为返回**真正折成**的条数（组成功按组计，
  逐条回退时逐条计；没折上的几条只画手折参考草图，不算）。
- `GenerationResult` 新增 `auto_bend_failed_count`；`bend_count` 用真实值。
- 界面：单件完成提示改「已自动折弯 N 条；另有 M 条折不上，折弯线草图
  「折弯线_手折参考」已保留，需在 SolidWorks 里手折」；一键导出结果列表显示
  「折弯 8 条，4 条未折（折弯线已留）」；完成进度汇总报「其中 N 件部分折弯未成」，
  并在日志里列出件号与条数。

### 件03 为什么只折得动 8 条（实测）

件03 的 12 条折弯线是两组互相跨越的角部短折弯：8 条竖直（x=2746.9/2852.9/3548.9/3654.9，
各 25mm，靠近上下边）+ 4 条水平（y=5602.3/5096.8，各 25mm，离板边 27mm）。实测：

| 方案 | 结果 |
| --- | --- |
| 先竖直 8 条 → 再水平 4 条（现状） | 8 条成功，水平 4 条 `InsertSheetMetal3dBend` 全参数失败 |
| 先竖直 → 水平 4 条改用图纸原长（不贯穿） | 仍 4 条失败 |
| 先竖直 → 水平 4 条反向折 | 仍 4 条失败 |
| 先水平 4 条 → 再竖直 8 条 | 4 条成功，竖直 8 条连折弯线草图都建不出来 |
| 先水平 → 竖直改用原长（不贯穿） | 仍 8 条建不出草图 |

结论：折弯后 SolidWorks 只肯在同一批「未被已有折弯打断」的平面区域上做草图折弯。
件03 两组线互为对方的跨越边界，无论谁先折，另一组都跨不过去。当前保留折 8 条（多数）
+ 4 条折弯线手折，是这套「贯穿式草图折弯」能做的最好结果。要全自动需要改走
边线法兰（`InsertSheetMetalEdgeFlange`）路线，属下一轮大改。

## 释放槽方向：贴板边的槽要跨过板边开成缺口

用户指出「主要是开槽的方向问题，有些要这样扩槽」：槽跨在板边上（一半在板面内、一半越出板边），折弯端头才能与板边断开。以前所有扩槽都只朝板面（材料内）加深，贴边的槽永远开不成跨边缺口。改成：

1. **贴边矩形槽孔 → 外轮廓缺口**（`convert_border_hole_to_notch`）：槽孔一边与外轮廓边共线时，扩槽不再按内孔处理，而是把外轮廓那条边挖成缺口（三边直角、不斜切），并从孔列表删除该孔——与外环相交的内环 SolidWorks 不接受，越过板边的部分也没有材料可切。
2. **细缝拉伸**：孔离板边只剩 ≤0.75mm 细缝（图纸画法/浮点误差）时，先把那一侧拉伸到板边再开缺口，不留悬空窄条。
3. **板边附近的交汇补槽跨边**：折弯线交汇点/端头距板边 ≤2mm 时，补槽矩形直接从板边伸进材料（跨过端头），并转为缺口；找不到可贴的直角边就退回原来的板内孔。
4. **部分搭边不转**：孔口只有一小段搭在板边（覆盖 <80%）时保持为孔，避免缺口切不干净。
5. **沿边加宽不越界**：缺口口部沿板边加宽时 clamp 在外边端点内，不会把轮廓顶点推出自交。

每级扩槽仍长宽各 +1.0/+0.5mm：缺口深度朝材料内加深、口部沿板边加宽。

## 折弯失败最多试 3 次，之后直接出平板 + 折弯线

以前自动折弯失败会逐级扩大释放槽，最多 6 级，每一级都要重开文档、从轮廓重画整件，看起来像「一直在重复画图」。按「折弯失败 3 次就可以直接生成零件，把折弯线留下让我来手动」改成：

1. **尝试上限 = 3**：`MAX_AUTO_BEND_ATTEMPTS = 3`（`MAX_RELIEF_STEPS` 相应变成 2，relief_step 0/1/2，累计扩槽 0 / +1.0 / +1.5 mm）。第 3 次仍失败就不再重开机，直接出「平板 + 折弯线草图」。
2. **结果里带标记**：`GenerationResult.auto_bend_attempts` / `auto_bend_abandoned`，一眼看出这件是自动折成、平板未折，还是折弯失败退回手折。
3. **提示说清楚**：单件弹窗写「自动折弯尝试 N 次仍未成功，已改为平板件；折弯线草图『折弯线_手折参考』已保留，请选它做草图折弯」；一键导出的结果列表也把 `auto_bent=False` 换成「折弯失败 3 次→手折（草图已留）」，并在完成进度里报出需要手折的件数。
4. **重试进度可见**：生成时状态行显示「自动折弯第 1/3 次…」，失败后显示「释放槽已扩大，重新画件」，不再像卡死。

图上的折弯线仍按原长画进「折弯线_手折参考」草图，和以前一样。

## 车件：螺纹跟底孔一起长在模型上

上一版只把螺纹写进零件备注，模型上只有一个光孔；孔底是平底，而图纸是钻出来的锥底。按「是带钻头的，螺纹是同步的」改成：

1. **螺纹做成装饰螺纹线**：生成时对每个内螺纹孔，按「孔口轴向 + 底孔半径」换算出孔口圆边的世界坐标点，选中圆边后调用 `InsertCosmeticThread3`（ISO 公制、盲孔、按公称直径与有效深度）。孔是旋转剖面挖的，螺纹作为子特征挂在同一个旋转特征下，模型与工程图都能直接看到。
2. **孔底改成 120° 钻尖**：旋转剖面里的内螺纹孔本来就有锥尖；这次把 `plan.holes`（文字标注的钻孔，如「Φ8 深20」）挖出的平底圆柱也改成锥底，锥深 `r/tan60°`，不超过孔深一半。
3. **螺纹参数从标注读**：`TurnedThread` 之外新增 `TurnedBore`，记录底孔半径、孔口/孔底/锥尖轴向、公称直径、螺距、有效螺纹深。螺纹深优先读「内M12-25深」，没写就按孔深留 2.5 倍螺距的钻尖余量。粗牙螺距查表（M6=1.0、M8=1.25、M12=1.75…）。
4. **自定义属性写全**：`螺纹` 属性带成 `M12 深25（底孔Φ10.11，钻深30.0，120°钻尖）`，车工一眼看得懂。

实测：

- A-01 皮带座支撑柱 → 装饰螺纹 M12，孔口 x=74、大径 12、深 25，孔底 Φ10.11 钻尖到 39.64；
- A-019 滚筒轴芯3 → 装饰螺纹 M6，孔口 x=200、大径 6、深 12.5（末端孔口也定位正确）；
- 其余 18 张车件图无内螺纹孔，几何不变。

选边失败时只记警告、退回到「仅写属性」，不会中断整批。

## 车件：两端台阶 + 内螺纹盲孔（A-01 再修）

上一版把 A-01 的 Φ15 当成了通孔，转出来是一根「外 Φ20、内 Φ15」的管子，和图纸不符。图纸实际是：

- 总长 74；中段 Φ20 长 68；**两端各 3mm 车到 Φ15**（端面 0.5 倒角）；
- 右端 **M12 内螺纹**，螺纹有效深 25、钻孔深 30，孔底 120° 钻尖。

四处根因，逐个修掉：

1. **Φ15 被误判成通孔**：判定只看「该档位的线段合并跨度是否接近全长」。两端台阶各画 3mm，合起来跨度 73，也接近全长，但中间断开 68——那空档正是实心轴身。现在要求孔壁线**连通**（最宽断裂 ≤ 跨度 15%），两端台阶不再进内孔。
2. **内螺纹孔根本没挖**：孔壁只有 30/74 长，达不到「通孔」门槛，于是整根按实心轴做。现在按标注里的 `M值` 找孔壁线：贴着一端面、连续、半径小于该处外圆的那一条带，取孔口与孔底；再找孔底往轴心收的锥线定钻尖。孔按**底孔**挖（M12 → Φ10.1），螺纹写在零件备注里——攻丝才切得动。
3. **3mm 台阶被缩放吃掉**：窗口两端原来各留 2% 余量再整体缩放到标注总长，台阶被压成 1.4mm 且整体偏移。现在用材料线段的真实起止当窗口，并把台阶边界回贴到图上的竖直台阶面，A-01 得到精确的 0–3–71–74。
4. 顺带修掉 `axis_source` 重复拼成 `dimensions+dimensions`。

A-01 现在的剖面：`(0,0) → (0,7.5) → (3,7.5) → (3,10) → (71,10) → (71,7.5) → (74,7.5) → (74,5.05) → (44,5.05) → (39.64,0)`，旋转即得两端带台阶、右端带 M12 螺纹底孔（含钻尖）的柱。

其余 19 张车件图重跑，外径、长度、螺纹与上一版一致，没有回退。

## 车件：套类零件（带内孔）修复

> 注：这一版把 A-01 的 Φ15 读成了通孔，结论有误，已被上面一节取代。轴线与内孔识别的其余改动仍然有效。

A-01 皮带座支撑柱转出来是一根带一圈圈细环槽的实心竹节轴。三个叠加的根因：

1. **轴线估偏 5mm**：轴线原本靠剖面里的圆弧圆心推算，填充边界、退刀槽的小圆弧把轴线带到 y=97.2（真实在 102），所有半径随之全歪。现在优先用直径标注的中点定轴线——Φ20 量的是 92→112，中点 102 就是轴线，比弧心稳得多。
2. **孔径混进外径档位**：Φ12（内螺纹孔）被当成外径台阶。现在自动识别内孔：比外径小的档位，若孔壁线跨度和外径线相当、且外径线盖住它跨度六成以上，判定为内孔（外径台阶不可能画得比最大直径的轴身还长；细长的外径台阶盖不满孔跨度）。内孔从外径档位剔除。
3. **剖面被强制闭合到轴线**：`_simplify_profile` 无条件把剖面两端拉回轴线，挖好的孔又被填实。现在环形剖面（通孔）不收口，旋转后直接得到套；盲孔从孔口挖到孔底、孔底留平。

另外：标注文字是「内M<>-25深」这种占位写法时（数值在标注实体上不在文字里），螺纹现在从标注实体补读，备注占位符替换为真实数值（内M12-25深）。

实测 20 张车件图：A-05 侧压轮座连接轴得到环形剖面（外 Φ15、孔 Φ8）；其余轴类结果不变，另补出 A-012/A-018/A-019/A-02/A-08 上此前漏读的螺纹标注。

## 修复「厚度全是 2mm」

图顶那排「碳钢板2.0mm / 2.5mm / 4mm / 5mm / 6mm」是**分区大字**，一颗管一整列，纵向贯穿整张图。原来的挂法有两处不对，结果 46 个件全被塞成第一颗字的厚度：

- `parse_thickness_value` 不认「碳钢板2.0mm」这种材质+数字的写法，5 颗大字里只认出 2 颗；
- 挂靠按行（`_row_bands`）做，同高度的零件被合并成一整行的框，5 颗大字全落进这个框，只取第一个。

现在：

- 材质名后面直接跟数字也算板厚（碳钢板/不锈钢/铝/黄铜/冷拔/SPCC/Q235 …），单测覆盖 2.0/2.5/4/5/6。
- 图纸顶端同一高度带上的大字切成一列一条带，**每个零件按自己所在的列取该列大字**，整列共用。列条带覆盖不到的件再退回到「本行头顶最近的字」。
- 只有横向排开（≥2 颗、同一高度带）才算分区大字；散落在各处的「2mm」「1.5mm」仍是逐行标注，一次只给一行用，不会横向串到别的行。

实测 `QL-5050左右驱动封箱机钣金下料图.dwg` 46 个件：2.5mm × 26、2.0mm × 7、4mm × 6、5mm × 5、6mm × 2。

## 修复「钣金图加载半天不出来」

上一版加车件标注解析时，`collect_dimensions()` 对每个块参照都调用 `virtual_entities()` 全量展开。钣金图上块动辄上千个，即使块里根本没有尺寸标注也照样展开一遍，一张图分析十分钟都出不来。`collect_text_entities()` 原有写法也有同样问题。

现在收集标注和文字前，先看块定义里有没有目标实体，没有就跳过。同一张 `QL-5050左右驱动封箱机钣金下料图.dwg`：修复前 10 分钟以上（用户被迫关程序），修复后 **7.26 秒**（轮廓 288、折弯线 143，与修复前结果一致）。

## 车件：改成读图纸标注定尺寸

以前车件只靠几何线条猜外径和长度，真实图纸上算出来是 Φ0.6、Φ1.1 这种明显错误的值。原因是车件图的主视图外面套着尺寸线框（A-03 的框宽 428.8，而真实轴长只有 168），圆也多是标注引线的小圆。

现在：

- 解析 `DIMENSION` 实体（含块内展开），拿到真实标注：直径、半径、沿轴长度。20 张真实车件图里 19 张带这种标注，例如 A-03 有 Φ28/Φ15 和 168/128/58.5/40.5，A-013 有 Φ60/Φ44/Φ35/Φ28。
- 用标注直径档位去筛几何线段——线框和引线的半径不可能等于任何一个标注直径，这一步比按包围盒估上限可靠得多。
- 按图上实际画出的台阶位置分段（两端台阶、单端台阶、光轴都能处理），标注数值负责校准。用户确认以标注为准。
- 图框圆角那种夸张的半径标注（如 R10248）会被自动剔除，不会把外径撑成 Φ20498。
- 图纸只标分段、没标总长时（如 A-01 最大只标 74），用几何跨度兜底。

`DrawingAnalysis` 新增 `dimensions` 字段；`collect_dimensions()` 负责抽取。

## 修复「识别不出轮廓、点了没反应」

两个独立的原因，都会让右侧零件列表出不来：

- 密集连通区域的找环搜索是指数回溯，遇到整张图框/密集标注就永远跑不完（真实钣金图上 90 秒都出不来结果）。现在单次搜索有节点预算，超预算的起点直接跳过，同区域其它干净轮廓照常抽出。同一张网格，旧代码 30 秒超时，新代码 0.4 秒。
- `contained_hole_indices` 用 `next()` 取选中轮廓，退化轮廓（零面积、点太少）被包围盒过滤后直接抛 `StopIteration`，整个右侧列表构建失败、一行都不显示。现在退化轮廓按「没有内部孔」处理。真实钣金图列表由 0 行恢复为 66 行。
- 图名写明「钣金图/展开图」时不再因为图里画了一根滚筒而整体判成滚筒尺寸图。

## 可编辑草图 + 按行导出

- 默认不再用 `InsertDwgOrDxfFile2` 导入 CAD。外轮廓、孔和折弯线都由草图管理器重画，草图可以改。需要直导时给生成函数传 `cad_import=True`。
- 红线和「中心线」层折弯线保持原来的端点和长度，不再接长或拉到轮廓外。
- 一键全部导出会先弹窗：件数、输出目录、找不到大字时的默认板厚、折弯半径和角度。点「开始导出」才生成。
- 厚度读每行顶部的大字，挂到该行每块件上；没有大字就用弹窗里的默认板厚，并写入日志。
- 文件名按从上到下、从左到右：`01×2 2mm.SLDPRT`。件数优先用图上的「J1 X 2件」。
- 释放槽仍是矩形、不斜切。扩槽只朝板面加深。规则和出处见 `BEND_RELIEF.md`。
- 折弯特征草图会沿原方向穿出板边约 1mm，否则短红线折不成。识别长度和「折弯线_手折参考」不变。同草图一次折失败后改为分组再逐条。扩槽最多到累计 +3.5mm，以便越过中心线约 3.4mm。

# 折弯释放槽

生成时折弯位置固定为折弯中心线（SolidWorks 草图折弯 `Position = 1`）。草图折弯不会自动开释放槽，槽必须画在基体轮廓上。

## 依据

- SolidWorks 自动释放槽：矩形 / 撕裂（Tear）/ 长圆（Obround）。矩形和长圆的 `d = 释放比 × 板厚`，这个 `d` 既是槽宽，也是槽边超出折弯区的深度。释放比 0.05–2.0。见 [Auto Reliefs](https://help.solidworks.com/2021/english/SolidWorks/sldworks/c_auto_reliefs.htm)。
- SolidWorks 最佳实践：Sketched Bend **不会**自动加释放槽。折弯线靠近边缘、尤其用 Material Inside 时，相邻边会被一起折弯。见 [Sheet Metal Best Practices](https://my.solidworks.com/docs/BP/TS_BP_SWX_Sheet_Metal.pdf) 第 15 节。
- SendCutSend：槽宽至少 `0.5 × 板厚`；槽深从折弯线量起，至少 `板厚 + 内半径 + 0.5 mm`。SolidWorks 自己的深度是从折弯区边缘起算，不是从中心线起算。见 [Bend Reliefs](https://sendcutsend.com/blog/guide-to-designing-bend-reliefs/)。
- Inventor：矩形槽常见于手工下料（锯缝）；泪滴槽用于紧折弯；圆槽多由激光切出。深度是超出变形区的那段。
- 车间工艺切口：槽宽 `k ≥ t`，槽深 `L ≥ t + R + k/2`。局部弯曲要避开尺寸突变处。

## 和现场实测合在一起

用户机器上，能不能折成主要看槽往**板面**越过折弯中心线有多深，大约要 **≥ 3.4 mm**。往翼板一侧扩几乎没用。`t = 2`、`R ≈ 1` 时，SendCutSend 的 `t + R + 0.5 ≈ 3.5 mm`，和这 3.4 mm 是同一量级。

因此：

1. 图上已有的矩形槽原样保留，不斜切，step 0 不扩。
2. 第一次折弯失败：长、宽各 **+1.0 mm**，整份加在朝板面的一侧，不两侧均分。
3. 之后每一级再 **+0.5 mm**，仍然只朝板面。
4. 图上没有槽时不要先开一条固定长槽。折弯失败后，向上和向内各加一点点（先 1.0 mm，之后每次 0.5 mm），两个方向都加，开口不要一下开大。四角保持直角。
5. 超时或扩到上限仍失败：退回平板，并留下「折弯线_手折参考」草图。这份参考草图用图上的原长。折弯特征草图另沿原方向穿出板边约 1mm，否则短红线穿不过板面，草图折弯会被拒绝。
6. 同草图一次折失败后，先按平行分组再逐条折。经验上扩槽累计到 +3.5mm 才过得了约 3.4mm 的中心线深度，但每一级都要重开文档、从轮廓重画整件，代价很高。
7. **自动折弯最多试 3 次**（`MAX_AUTO_BEND_ATTEMPTS`，relief_step 0/1/2，累计扩槽 0 / +1.0 / +1.5 mm）。3 次还折不起来就直接出「平板 + 折弯线草图」，不再重画整件；槽没有扩到 3.5mm 的件交给人手折。
8. **方向不是一律朝板面**：槽贴着板边（或离边只剩细缝、交汇点距边 ≤2mm）时，要**跨越板边**开成缺口——一半在板面内、一半越出板边，折弯端头才与板边断开（`convert_border_hole_to_notch`）。只有板内部的槽才朝板面加深。缺口口部沿板边加宽时不越过外边端点，避免轮廓自交。

## 4. 会话安全缺口清单（硬核，相对验收计划 §6）

1. **未知会话**：已有会话 + 用户文档时，任务是否拒绝写/拒绝 teardown，文档与 PID 原状。
2. **并发第二写者**：已有任务持有写锁时，第二任务是否立即拒绝且不 CloseDoc。
3. **超时**：看门狗触发后是否停止继续写、不杀未证明 PID、可留恢复证据。
4. **COM 断连**：出图中途断连是否不 ExitApp、不按名杀、owned 文档策略与轴件 `partial_com_disconnect` 语义一致（当前桌面轴路径已有，出图路径未单独证明）。
5. **一键按钮路径**：UI 启动是否复用同一套 lease/独占证明，失败是否可恢复且不冒充成功。
6. **证明边界**：仅 Dispatch/GetActiveObject、PID 不匹配、外来文档 → 不得 ExitApp（模拟已覆盖；实机未覆盖出图链路）。

## 6. 下一步实机硬测用例（只列步骤，本回合不执行）

### H1 · 未知会话拒写
1. 用户手动开 SW，打开任意非任务零件并保持前台。  
2. 干净命令行启动出图一键/生产导出（指向 stabilized 缺件包）。  
3. 期望：拒绝独占写或明确 attach 策略文档化；用户零件仍打开；无 ExitApp；result 记 `not exclusive` / 等价。  
4. 证据：result.json、会话 PID、用户文档仍在、无 process kill。

### H2 · 并发第二任务
1. 第一任务已占用出图写（或持有 lease）。  
2. 立刻再启第二出图任务。  
3. 期望：第二任务立即拒绝；第一任务文档不被 CloseDoc；无双写。  
4. 证据：两份 result、时间线、打开文档列表。

### H3 · 超时不继续写
1. 人为拉长/卡住一次 COM 调用（或把超时调到极短仅用于受控实验）。  
2. 期望：看门狗记超时；之后无新 CAD 写；未证明 PID 不被杀；可恢复或干净失败码。  
3. 证据：日志含 watchdog 文案、文件哈希未在超时后漂移。

### H4 · 出图中途 COM 断连
1. 在 CreateDrawView / BOM / SaveAs PDF 之一后模拟或触发断连（与轴件同观察点）。  
2. 期望：不 ExitApp；已落盘 SLDDRW/PDF 策略明确（保留或 partial）；状态码可区分。  
3. 证据：exit code、是否 `partial_*`、磁盘产物、PID 仍在。

### H5 · 一键端到端冒烟（会话维度）
1. 专属洁净 SW 实例 + 新输出目录。  
2. 点真实一键：选装配、配置、输出目录。  
3. 期望：与 CLI stabilized 同验收条；失败可取消且不冒充成功；专属 PID 正常收尾（仅证明拥有时）。  
4. 证据：UI 截图/录像、result、PDF/SLDDRW、源文件哈希不变。

# 参数化建模工作台

启动 `python app.py`，点击左侧“参数化建模”。

工作台现在包含“参数与函数 / 模型与绑定 / 变更预览与执行”三页。支持原有 A01 JSON、Gork 滚筒机架 JSON/YAML，以及新增带单位/约束的数学函数规则；支持导出参数与映射，也可在明确审核后新建可编辑零件或修改已有独立零件的副本。

完整操作步骤、规则格式、API/CLI、严格会话策略与 Gork 验收命令见 [函数建模与副本改型](function-modeling-v10.md)。计算/Save3/读回结果只进入待复核，Windows/SolidWorks 和工程验收仍需实机完成。

原有 A01 与机架规则的边界继续有效：初始1800×900×1500仅为示例目标；未知尺寸不补默认生产值。机架 W 是侧板内侧净距，L 是机架长度，H 默认通过支腿调整；88.9 mm 节距及历史测量须在当前模型复核。原机架包不包含滚筒零件自动改型，不能将母体455H套给650H机型，也不能用孔阵列改动冒充侧板长度联动。

导出方案包含 request.json、plan.json、model-mapping.json、machine-spec.json、SHA256.json。修改输入或源规则会使旧预览失效。原“目标包络 / 参数规划”队列入口仍保留；新已有零件流程只写已审核的正值线性尺寸，未绑定参数只计算，多文件与整机联动不在本批原生执行范围。

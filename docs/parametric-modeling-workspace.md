# 参数化建模工作台

启动 `python app.py`，点击左侧“参数化建模”。

1. 输入目标长、宽、高（mm）。初始1800×900×1500只是示例目标，不是实测模型尺寸。
2. 点击“计算参数与依赖”，查看目标参数、依赖和待确认项。未知尺寸不补默认生产值。
3. 点击“保存方案与模型映射表”，选择父目录；程序自动新建方案目录，不覆盖既有目录。

可导入符合现有 `a01_parametric.config.load_spec` 契约的机型规则 JSON，以及Gork交付的滚筒机架 `frame.yaml`（同结构JSON也支持）。导入不执行Python、宏或自由公式，YAML使用safe_load。

滚筒机架规则中，W是侧板内侧净距，L是机架长度，H默认由支腿调整，孔距为88.9 mm。历史测量值只用于方案推算，均保留待复核状态；名义宽度与实测内档冲突会显示警告。仅阵列映射不能证明板长变化，换边不能只移动齿轮或遗漏固定板/挡板。这个机架包不含滚筒零件自动改型，不能把其母体455H直接套到用户650H机型。

导出内容：

- `request.json`：目标尺寸、规则来源及SHA256、方案审查摘要和未执行模型声明。
- `plan.json`：复用现有A01依赖求解器的参数计划和未解决项。
- `model-mapping.json`：待确认的文档、配置、特征、尺寸、单位、范围和来源映射模板。
- `machine-spec.json`：本次规则快照。
- `SHA256.json`：上述文件的哈希。

修改输入会使旧预览失效；规则文件变化或方案被修改后拒绝导出旧结果，要求重新计算。操作及错误沿用运行记录日志。

此版本实现参数规划、依赖预览及模型映射交接，没有开放真实SolidWorks改型按钮。实际模型修改须确认尺寸绑定、接口保护与范围，并通过共享回执、会话所有权和串行写入门禁。方案成功不代表已生成模型、更新装配、工程图/BOM或通过生产验收。旧“目标包络/参数规划”队列入口保留。

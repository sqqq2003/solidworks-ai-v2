# 工作台框架审核修订

基于 `79b95d7`，本次处理五项审核发现，未合并尚待验收的 PR #7。

1. 重开验证统计所有实体的面包围盒、实体数量和整体包络；可指定 expected_body_count。缺预期尺寸仅返回 reopened_rebuilt，有尺寸对比返回 reopen_dimensions_verified。二者 geometry_verified=false，不再把包络检查称为完整几何验证。滚筒不再拿第一个实体的生成结果作为独立的完整零件期望值。孔、折弯、螺纹等关键几何仍需专门验收。
2. 旧整机入口必须明确 machine=GT-ZX。GUI 提供明确机型选择，默认 QL-5050PX 的请求会被拒绝并指向独立 QL 流水线 PR #7，不会静默使用旧数据。本次完成机型隔离，没有提前合并或宣称接通整个 QL 工作流。
3. `confirm_job(job)` 绑定源图 SHA256 和完整任务选项摘要；原生任务启动前重新检查。GUI 改变通用默认值选项也会取消确认。JSON 原生清单必须由用户审核后通过 confirm_job 生成确认字段，不能只填 confirmed=true。超时等任务选项改变也需要重确认。确认前的识别结果仍需由操作者核对；文件在校验后被并发修改的极短窗口尚未以只读快照彻底消除。
4. 任务默认等待 600 秒，可设置 timeout_seconds。日志写入 runtime/project-workers。超时返回 timed_out、PID、日志位置和恢复标记，停止本批后续任务，不终止 Python 或任何 SolidWorks。原生任务采用独占创建的 native.pending.json 防止重复启动；超时或父程序崩溃后保留标记，新原生任务拒绝执行。必须先人工确认旧 worker 退出及 SW 文档会话归属、保存诊断，再移除标记。不要仅因超时删除。该机制限制等待时间，不提供强制取消 COM 调用。
5. 交接包仅收集 Git 跟踪且命中源码路径/扩展名白名单的文件。未跟踪客户参数 JSON/TXT 不再被自动收集；HANDOFF.json 记录跟踪文件工作区是否有改动和收集策略。不再自动附带可能属于旧源码的 latest.json 测试结果；需在对应版本另行执行和记录测试。

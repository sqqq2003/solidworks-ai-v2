## 实际修复

solidworks_generator._set_sw_automation_mode原来每次设置UserControl=False。SW官方CloseDoc说明：后台会话关闭最后文档会退出，即使代码没有调用ExitApp。

- keep_application_open=True的已证明独占会话使用UserControl=True，并严格读回。
- CloseDoc/CloseAllDocuments在原归属门禁之后再次核验保活；读回失败直接阻断CloseDoc并保留现场。
- 不接管已有实例，不开第二个替代会话，不放松foreign/STA/PID/文档身份验证。
- 最终空文档的显式ExitApp仍保留；UserControl=True会让本任务SW界面可见，这不是未知会话授权。
- 同批补齐typed IMathUtility + 显式SAFEARRAY(double)点编组，避免把普通tuple作为VARIANT数组交给SW2022；仍以原生数学读回硬门槛阻断错误草图。

依据：https://help.solidworks.com/2021/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ISldWorks~CloseDoc.html

## 精确复测步骤

完整SHA以本次派单消息为准，填入$Sha。WB先跑完并退出，再由Qoder跑，不能同时占SW。若存在未知SW实例，停止并回报，不自动关闭。

```powershell
$Role = 'workbuddy' # Qoder复测时改为qoder
$Sha = '<本次派单的完整提交SHA>'
$Repo = "C:\Users\yue\sw-ai-run-packs\$Role\s2-keepalive"
# 必须新目录；已存在时选新名称，不覆盖旧证据或强制切换脏工作树。
git clone --single-branch --branch dev/cloud-ai https://github.com/sqqq2003/solidworks-ai-v2.git $Repo
if ($LASTEXITCODE -ne 0) { throw 'clone failed; stop' }
Set-Location $Repo
git switch --detach $Sha
if ($LASTEXITCODE -ne 0) { throw 'checkout failed; stop' }
if ((git rev-parse HEAD) -ne $Sha) { throw 'wrong baseline' }
py -3 -m venv .venv
$Py = Join-Path $Repo '.venv\Scripts\python.exe'
& $Py -m pip install -r requirements-cloud.txt pywin32
if ($LASTEXITCODE -ne 0) { throw 'dependency setup failed; stop' }
$env:PYTHONUTF8 = '1'
$Sw = 'D:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\SLDWORKS.exe'
$Out = "D:\工程\钣金导入\${Role}_s2keep_$(Get-Date -Format yyyyMMdd_HHmmss)"
& $Py -X utf8 work/prepare_s2_retest.py --out $Out --sw-exe $Sw --thickness 2.5 --radius 1 --angle 90 --k-factor 0.4
if ($LASTEXITCODE -ne 0) { throw 'fixture preparation failed; stop' }
& $Py -X utf8 work/project.py doctor 1> (Join-Path $Out 'doctor.json')
& $Py -X utf8 work/probe_owned_solidworks.py --sw-exe $Sw 1> (Join-Path $Out 'probe.json') 2> (Join-Path $Out 'probe.stderr.log')
if ($LASTEXITCODE -ne 0) { throw 'owned-session probe failed; stop' }
$Plan = Get-Content (Join-Path $Out 'retest-plan.json') -Raw | ConvertFrom-Json
$Exe = $Plan.command_argv[0]
$ArgList = $Plan.command_argv[1..($Plan.command_argv.Count-1)]
& $Exe @ArgList 1> (Join-Path $Out 'live.json') 2> (Join-Path $Out 'live.stderr.log')
$LiveExit = $LASTEXITCODE
$LiveExit | Set-Content (Join-Path $Out 'live.exit.txt')
& $Py -X utf8 work/check_sheet_metal_evidence.py (Join-Path $Out 'live.json') 1> (Join-Path $Out 'evidence-review.json')
```

上面2.5/1/90/0.4仅是WB已测100×80合成fixture的显式测试输入，不是OEM或生产默认。prepare自动解析轮廓并记录零基profile、DXF SHA256、4个加载模块SHA256及完整argv；不手填旧p248编号。

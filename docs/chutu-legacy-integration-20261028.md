# Chutu_SW 原程序功能借鉴

来源为用户桌面 Chutu_SW.lnk，快捷方式指向 D:\工程\出图自动化\一键出图_从SW取总装.vbs；只读检查，未运行、复制或修改原程序及模板。说明文件之间有四张和五张两种表述，当前快捷方式脚本检查五张文件，实际本轮未复测。

## 已找到的功能

chutu_oneclick.py 包含总装 COM 数据、BOM 数量、总体尺寸、表格/红框/下料文字、字体及布局；chutu_banjin.py 负责钣金图文字与模板；chutu_sheets.py 基于配置与模板分张、分类并创建按机器命名的新材料表目录。TEMPLATE_README 描述五种 DXF：钣金、方管、明细、总图、三视图，支持模板内容及尺寸填充。template 文件及规则可能含特定机器图形和数据，不应直接当作任意机器的几何来源。

现有源码显示总体尺寸优先读 SW 或配置，存在硬编码回退；图形继承模板，不足以证明总装尺寸改变后所有视图几何会同步更新。当前只确认出图/数据处理路径，本次未找到对总装尺寸写入的证据，不能据此宣称整机改型已实现。进一步核对用户所指的其它整机改型入口。

快捷方式依赖当前活动 SolidWorks，会覆盖 active_asm.txt，路径和机器名固定，且以现存文件数量检查五张图；旧产物可能导致误判，不能直接用于新程序安全门禁。必须逐任务使用独占会话、输入/输出隔离和新目录，并对每张新文件绑定任务、源哈希、参数、生成时间和内容检查。原始工程不得覆盖。

## 分阶段融入

1. 先以只读方式核对用户的模板结构、五图内容、字段、图层和字体；从实际图纸中建立非生产样例与对照，不推送客户图纸。
2. 复用已有 BOM、图层分类和版式思路，在独立输出目录生成五张测试图；配置尺寸必须有来源和确认状态，缺失则阻断或显式待确认，禁止静默沿用硬编码值。
3. 用用户已有模板对比图纸区域、行数、分类、数量、图层、字体和布局；测试缺字段、缺引用、旧文件和失败后重试，不把模板文字替换当作真实模型几何更新。
4. 接入已验证的 SolidWorks 复制件测量和参数改型流程后，针对每张图检查来源与输出内容的一致性；先做离线、再做隔离实机、最后工程与首件验收。
5. 经用户确认后选择可移植模板和明确的许可边界；继续保留原程序，不直接运行它的固定输出脚本或覆盖已有材料表。

本文件只描述静态源码检查，未证明任一新增路径已实现或达到生产验收。
